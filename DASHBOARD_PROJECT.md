# Agent Dashboard

This integration adds schema-driven dashboard planning, editing, revision-aware
saves, query execution, templates, and fixed or live publication to the DB-GPT
Data Assistant.

Start with the [documentation](docs/dashboard/README.md),
[design](docs/dashboard/DESIGN.md), [retail example](docs/dashboard/demos/walmart.md)
and [financial example](docs/dashboard/demos/apple.md).

The integration uses shared chat, attachment and scheduled-task interfaces.
Review scope, tested revisions and remaining checks are maintained in
[PR #3278](https://github.com/eosphoros-ai/DB-GPT/pull/3278).

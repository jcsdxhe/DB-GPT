# Dashboard walkthrough for PR 3278

This folder hosts the 17 approved PR screenshots from frontend commit `8de034311e4e57feca99a9c9bfc03dfcb85bcec6`.

The sequence covers home-page input, the dashboard-builder skill, visible tool execution, plan confirmation, the editable workspace, natural-language annotations, proposal review, explicit batch application, publishing, template selection, and distinct marketing and voice layouts.

These are UI demonstrations using fixed sample data and replayed API / SSE responses. The model label `demo-replay` identifies a demonstration. Visible execution summaries do not represent hidden model reasoning. These pictures do not claim a new live-model, production-backend, or performance test run.

English wording and demo layout choices are presentation settings. Some remaining interface labels were translated in the capture browser; this does not claim complete application localization. Financial data is the repository's historical Apple SEC sample; marketing and voice examples use synthetic data.

Only image references from this folder are added to the PR showcase. Product code is unchanged by this asset commit.
